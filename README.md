# Axiom — Saber Tech Governance

Public investor interface for Saber Tech's governance workspace.

The interface reads published records from a Unison backend. GitHub Pages does not store accounts, membership approvals, proposals, or ballots. Member sign-in opens the backend's own workspace.

No example members, votes, or financial results are presented as live records. If the backend is unavailable, the interface explicitly shows that state.

The governance foundation includes versioned charter text and rule settings, scoped authority grants, time-limited appointments, appeals, and independently reviewed execution receipts. The initial charter remains a proposed draft until the authorized body's decision is recorded and independently reviewed. Publishing the software does not adopt it or appoint anyone.

Visitors can inspect the public registers and export the public foundation records. Membership cases and individual ballots are excluded from that export. The application records human attestations; it cannot itself establish corporate, academic, or clinical authority.

Deployment uses GitHub Pages from `main:/docs`, without an Actions workflow. Source strategy documents and backend credentials are not included in this public repository.
